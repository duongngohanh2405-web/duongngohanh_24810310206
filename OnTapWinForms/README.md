# Ôn tập Windows Forms – C#

Dự án gồm 5 bài thực hành WinForms, dựng giao diện trực tiếp bằng C# để dễ đọc và chạy thử.

## Các bài
1. **Service Charge Calculator** – nhập đơn giá, số lượng và phần trăm giảm giá; kiểm tra dữ liệu và tính tổng.
2. **IT Incident Form** – nhập thông tin sự cố, chọn mức độ ưu tiên/loại sự cố/thiết bị, đính kèm ảnh và xem nội dung tóm tắt.
3. **Inventory Manager** – thêm, sửa, xóa và làm mới danh sách hàng hóa; kiểm tra mã trùng.
4. **Dynamic Seat Selector** – chọn ghế trong sơ đồ 20 ghế, một số ghế bị khóa và giá vé thay đổi theo khung giờ.
5. **Delivery Dashboard** – bảng đơn giao hàng, tổng tiền, trạng thái, đồng hồ cập nhật, thêm nhanh bằng F2 và xóa bằng Delete.

## Yêu cầu
- Windows 10/11
- .NET 8 SDK
- Visual Studio 2022 hoặc IDE có hỗ trợ Windows Forms

## Chạy chương trình
1. Mở thư mục `OnTapWinForms` trong Visual Studio.
2. Mở `OnTapWinForms.csproj`.
3. Chọn cấu hình `Debug`, sau đó nhấn **F5**.

Hoặc mở Terminal tại thư mục dự án và chạy:

```powershell
dotnet run
```

Nếu dùng Visual Studio, hãy bảo đảm workload **.NET desktop development** đã được cài đặt.
